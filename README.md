# 🛒 ShopEasy - Simple E-commerce React App

A simple e-commerce product listing app built with **React** and **Tailwind CSS**, featuring:

- ✅ Product list fetched from [FakeStoreAPI](https://fakestoreapi.com/)
- 🔍 Search functionality
- 🛒 Cart system with item quantity tracking
- 📦 Persistent cart (using localStorage)
- 📄 Pagination or Infinite Scroll (toggleable)
- 💅 Styled with Tailwind CSS
- 🚀 Easily deployable to Vercel or Netlify

## 📦 Features

- **Product Listing** – Fetches and displays products from `https://fakestoreapi.com/`
- **Search Bar** – Filter products by title in real time
- **Product Card** – Displays image, title, price, and an "Add to Cart" button
- **Cart Page** – Shows added products, quantity, total price, and remove buttons
- **Pagination** – Choose one UX pattern (both are implemented)
- **LocalStorage** – Persists cart contents across browser sessions
- **Responsive Design** – Tailwind CSS ensures it looks great on all devices

---

## 🛠️ Tech Stack

- React (with Create React App or Next.js)
- Tailwind CSS
- React Router
- localStorage
- Optional: Redux Toolkit or Zustand for state management
